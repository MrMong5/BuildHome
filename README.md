# ТуваДом — сайт домов и объектов недвижимости

Адаптивный сайт-каталог для домов в Кызыле и Республике Тыва. В проект включены публичная витрина, карточки объектов, фильтры, избранное, заявка от покупателя и закрытая панель сотрудников.

## Что уже работает

- Каталог с поиском по диапазону цены, минимальной площади и материалу стен.
- Карточка каждого объекта: цена, общая площадь, участок, материал, этажи, год постройки, описание, коммуникации с отдельными характеристиками.
- Карта в карточке объекта через виджет Яндекс Карт, а также ссылки для открытия адреса в Яндекс Картах и 2ГИС.
- Форма заявки покупателя. Заявки сохраняются в `data/leads.json` и видны в панели сотрудников.
- Вход сотрудников, создание учётных записей администратором, добавление / редактирование / удаление / снятие с публикации объектов.
- Загрузка фотографий на сервер. Фотографии сохраняются в `public/uploads/`.
- JSON-хранилище данных без отдельной установки базы данных.
- Адаптация под компьютеры и телефоны.

## Запуск на компьютере

Нужен Node.js версии 18 или новее.

1. Откройте папку проекта в терминале.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте файл `.env` на основе `.env.example`:

   **Windows (PowerShell):**
   ```powershell
   Copy-Item .env.example .env
   ```

   **macOS / Linux:**
   ```bash
   cp .env.example .env
   ```

4. Откройте `.env` и замените `SESSION_SECRET` на длинную случайную строку, а `ADMIN_PASSWORD` — на надёжный уникальный пароль (не менее 10 символов). Эти значения нужно изменить до первого запуска.
5. Запустите сайт:

   ```bash
   npm start
   ```

6. Откройте публичный сайт: <http://localhost:3000>
7. Панель сотрудников: <http://localhost:3000/admin.html>

Администраторский логин и пароль берутся из `.env`. Учётная запись администратора создаётся при первом запуске, если файл `data/users.json` пуст. Пароль хранится в виде хеша. Из панели администратор может создать отдельную учётную запись каждому сотруднику.

## Важное перед публикацией

- Первые 4 объявления — **демонстрационные примеры**, а не подтверждённые предложения о продаже. Их можно отредактировать или удалить в панели сотрудников. Не публикуйте примерные сведения как достоверные объявления.
- Фото в демонстрационных карточках загружаются с Unsplash. Для реальных объектов загрузите собственные фотографии.
- Если не указать координаты объекта, карта покажет центр Кызыла. Точку можно уточнить на Яндекс Картах и внести широту/долготу в форму объекта. На карточке также есть ссылки на Яндекс Карты и 2ГИС с поиском по адресу.
- В текущем варианте данные сохраняются в JSON-файлы на сервере. Для публичного коммерческого сайта перед запуском настройте резервное копирование, HTTPS, постоянное хранилище сессий вместо стандартного `MemoryStore` и хранение данных на постоянном диске хостинга. На сервере, где файловая система временная, объекты и фотографии могут потеряться после перезапуска или redeploy.
- Для сотрудников нужно создать персональные логины; не используйте один общий пароль. Удаление демонстрационных объектов и изменение доступа выполняйте из панели управления.
- Форма заявки сохраняет контактные данные посетителя. Перед коммерческим использованием добавьте полноценную политику обработки персональных данных и необходимые согласия в соответствии с применимыми требованиями.

## Структура проекта

```text
tuva-dom/
├── server.js                # Сервер и API
├── package.json             # Зависимости и команда запуска
├── .env.example             # Пример настроек секретов
├── data/
│   ├── listings.json        # Объекты недвижимости
│   ├── users.json           # Учётные записи (хеши паролей)
│   └── leads.json           # Заявки покупателей
└── public/
    ├── index.html           # Публичный сайт
    ├── styles.css           # Стили и адаптивная верстка
    ├── app.js               # Каталог, фильтры, карточки, заявки
    ├── admin.html           # Панель сотрудников
    ├── admin.js             # Управление объектами, заявками и доступами
    └── uploads/             # Загруженные фотографии
```

## Карты

Встроенная карта использует виджет Яндекс Карт, в параметры которого передаются координаты объекта. Отдельные ссылки ведут в Яндекс Карты и 2ГИС с поиском по указанному адресу. Для автоматического определения координат из адреса (геокодирования) потребуется подключить соответствующий API и ключ, ограниченный доменом сайта.

Официальная документация: <https://yandex.ru/maps-api/docs/constructor/index.html> и <https://yandex.com/maps-api/docs/js-api/quickstart.html>.
